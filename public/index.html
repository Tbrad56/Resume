Self-Hosted Storage Server

Debian · Docker · WireGuard · restic · Backblaze B2

Jul 2026
  • Kept the server off the public internet entirely, with no port forwarding and no open inbound ports. All access runs through a WireGuard VPN, so a device must be enrolled before it can reach the host, and untrusted devices are limited to the two application ports they need.
  • Separated six services onto isolated Docker networks so that a compromise in one cannot reach the others, then verified the boundary by connecting into a running container and attempting to reach its neighbors. Both name resolution and direct connections failed, as intended.
